# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Educational Angular application demonstrating **classic NgRx** modules (Effects, Entity, Router Store, Component Store, Component, Data, Operators). The app presents 7 tabs with subtabs for each NgRx topic, each with working UI examples. State is observable via Redux DevTools using `@ngrx/store-devtools`.

This is the companion project to `../NgRx` (which covers NgRx Signal Store).

## Tech Stack

- **Angular** 21.x (standalone components, signals)
- **NgRx** classic: `@ngrx/store`, `@ngrx/effects`, `@ngrx/entity`, `@ngrx/router-store`, `@ngrx/operators`, `@ngrx/component-store`, `@ngrx/component`, `@ngrx/data`, `@ngrx/store-devtools`
- **@angular-architects/ngrx-toolkit** (installed for future use; `withDevtools` only works with Signal Store, not classic store)
- **Angular Material** (tabs, theme)
- **RxJS** 7.x
- **Package manager**: pnpm
- **Testing**: Vitest (with `@analogjs/vitest-angular`)

## Commands

```bash
pnpm install            # Install dependencies
npx ng serve            # Dev server (http://localhost:4200)
npx ng build            # Production build
pnpm test               # Run all tests (vitest run)
pnpm test:watch         # Watch mode tests
npx ng generate component <name>  # Scaffold component
```

## Architecture

- `app.config.ts` — central providers hub: `provideStore`, `provideEffects`, `provideStoreDevtools`, `provideRouterStore`, `provideEntityData`
- `app.html` — 7 main tabs via `mat-tab-group` with `ng-template matTabContent` (lazy loading)
- `features/01-07` — each feature has a wrapper component with nested `mat-tab-group` for subtabs
- `shared/interceptors/mock-api.interceptor.ts` — `HttpInterceptorFn` mock backend for `/api/users`, `/api/tasks`, `/api/products`
- `shared/models/` and `shared/services/` — shared data types and HTTP services

### Classic NgRx pattern per feature (01-effects, 02-entity):
- `store/*.actions.ts` — `createActionGroup`
- `store/*.reducer.ts` — `createFeature` + `createReducer` + `on()`
- `store/*.selectors.ts` — auto-generated by `createFeature` + `adapter.getSelectors()`
- `store/*.effects.ts` — `@Injectable` class with `createEffect`

### Template code examples
Use `[textContent]="propertyName"` on `<code>` elements to display code with curly braces — Angular templates interpret `{}` as block syntax.

## Topics / Tabs

1. **Effects** (4 subtabs) — install, testing, lifecycle, operators
2. **Entity** (4 subtabs) — interfaces, adapter, additional state, feature creator
3. **Router Store** (4 subtabs) — install, actions, selectors, configuration
4. **Operators** (2 subtabs) — install, operators usage (tapResponse, mapResponse)
5. **Component Store** (8 subtabs) — install, initialization, read, write, effect, lifecycle, comparison, usage
6. **Component** (3 subtabs) — install, *ngrxLet, ngrxPush (maintenance mode)
7. **Data** (9 subtabs) — install, architecture, metadata, actions, collection, services, dataservice, effects, reducer
